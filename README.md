# YouTube

Files and resources for my YouTube videos. Download the files for a series to follow along with the videos.

## Series

### [15 Days of DAX](15-Days-of-DAX/)

A day-by-day Power BI series on DAX, from the basics to more advanced patterns.

| Folder | Contents |
|---|---|
| `Source/` | The source data for each day (`Day1.xlsx`, `Day2.xlsx`, ...) |
| `PBIX/` | The finished Power BI report for each day (`Day1.pbix`, `Day2.pbix`, ...) |

To follow along, load the day's source file into Power BI Desktop and build the measures from the video. Open the matching `.pbix` to compare with the finished version.
